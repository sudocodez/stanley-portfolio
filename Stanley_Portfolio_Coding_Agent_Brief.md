# Stanley Developer Portfolio — Coding Agent Brief

## Goal
Build a modern, fast, responsive, accessible, interview-ready developer portfolio.

## Positioning
Stanley is an early-career software developer focused on practical web applications, APIs and problem solving. Do not exaggerate seniority.

## Stack
- React + Vite
- JavaScript (TypeScript only if the developer is comfortable maintaining it)
- CSS/CSS Modules or a lightweight utility approach
- No database
- No custom backend
- No authentication
- No secrets in frontend code

1. Hero

## Hero
Headline: “Building practical software from real-world requirements.”
Supporting text: “I'm Stanley, an early-career software developer focused on web applications, APIs and practical problem solving. I learn by building, shipping and understanding the systems behind what I create.”

## Featured project
**The 200 CEOs Business Forum**
Real client project / full-stack web platform.

Describe accurately:
- React/Vite frontend
- React Router
- Node.js/Express backend
- PostgreSQL
- REST/HTTP/JSON
- JWT/bcrypt authentication where applicable
- Nodemailer email integration
- Multer/S3-compatible storage where applicable
- SQLite → PostgreSQL migration as a learning/challenge story, without exaggerating ownership

## Design
- Premium editorial developer aesthetic
- Strong typography and spacing
- Restrained accent color
- Subtle motion
- Real project screenshots
- Mobile-first
- Accessible contrast and keyboard navigation
- Respect prefers-reduced-motion
- Avoid generic AI-template visuals and excessive glow/gradients

## Content guardrails
- Never invent metrics, users, revenue, clients or responsibilities.
- Never call Stanley an expert merely because a package exists.
- Use accurate wording: built, implemented, integrated, worked with, currently learning.
- Be transparent about AI-assisted development if asked.
- Never expose secrets.

## Deployment
The portfolio itself should be frontend-only and deployable to Vercel or Netlify. No backend is required for version 1.

## Definition of done
- Production build passes
- Responsive on mobile/tablet/desktop
- No broken links/assets
- Accessible navigation
- SEO metadata
- Strong 200 CEOs case study
- Working contact links
- README and deployment instructions
